# Керування прайсом Enigma Dent

Після оновлення проєкту виконайте:

```powershell
python manage.py migrate
```

Міграція створює таблиці прайсу і автоматично завантажує діючий прайс від 23.03.2026.

В адмінці:

- **Категорії прайсу** — розділ, назва, опис, порядок і видимість.
- **Позиції прайсу** — код, назва послуги, числова ціна або текстова ціна, примітка, порядок і видимість.
- Позиції також можна редагувати прямо всередині категорії.

Якщо треба показати `безкоштовно`, залиште числову ціну порожньою і запишіть `безкоштовно` у полі **Текст ціни**.
