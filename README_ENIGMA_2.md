# Enigma Dent 2.0 — коротко

Це не косметичний патч старого шаблону. Видима частина сайту побудована заново на чистих Django templates + власному CSS/JS.

Збережено бекенд:
- заявки на прийом;
- Django Admin;
- статуси заявок;
- відгуки та їх модерація;
- Telegram notifications;
- SQLite та існуючі міграції.

Новий модуль прайсу свідомо залишений наступним етапом, щоб спочатку затвердити ядро дизайну і UX.
